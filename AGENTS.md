# AGENTS.md

## Scope
- This repository is the ScoreSense frontend (Vite + React + Tailwind).

## Workflow
- Use `rg` for search and `rg --files` for listing files.
- Prefer `apply_patch` for single-file edits.
- Keep edits minimal and follow existing style.

## Testing
- Run `npm run lint` for linting when appropriate.
- Run `npm run test` only if a test setup exists.
